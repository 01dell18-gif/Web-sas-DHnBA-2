Impor Data Siswa

Unggah data siswa dalam format Excel (.xlsx) atau CSV dengan pencocokan kelas otomatis.

Unggah Berkas Siswa 📥 Unduh Template CSV
Format yang didukung: .xlsx, .xls, .csv (Maksimal 5 MB).
Format Kolom yang Dibutuhkan:
  • NIS: Nomor Induk Siswa (Opsional)
  • NISN: Nomor Induk Siswa Nasional (Opsional)
  • Nama Siswa: Nama lengkap siswa (Wajib)
  • Kelas: Nama kelas, misal: XII RPL 1 (Wajib, akan dibuat otomatis jika belum ada)
